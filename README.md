📌 Project Description

This is a simple Bank Transfer System developed using Java.
The application allows users to:

✅ Check account balance

✅ Transfer money from one account to another

✅ View updated balance after transfer

The system uses:

Java (Core Java)

Bean classes

Service layer

Database tables (ACCOUNT_TBL, TRANSFER_TBL)
